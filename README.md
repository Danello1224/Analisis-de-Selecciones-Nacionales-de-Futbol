# Football Soccer Data Engineering Project

## Football National Teams Data Lake & Analytics Pipeline

This project is a cloud-based data engineering and sports analytics solution focused on analyzing national football teams through a modern AWS Data Lake architecture.

The project simulates a real-world scouting scenario where the coaching staff of the Mexican National Team analyzes potential opponents before the FIFA World Cup 2026 using historical international football match data and analytical performance metrics.

The platform was designed to centralize, process, transform, and visualize football datasets using scalable AWS services, SQL analytics, and dashboard-based statistical exploration.

---

# Project Objective

Build a scalable sports analytics pipeline capable of:

- Collecting historical international football match data.
- Processing and cleaning raw datasets.
- Structuring information into analytical Data Lake layers.
- Generating football performance metrics.
- Enabling SQL-based analytical queries.
- Supporting scouting-oriented statistical analysis.
- Visualizing football insights through dashboards.

# Data Lake Architecture

The project follows a layered Data Lake approach:

```text
Raw Football Data
        ↓
Bronze Layer (Raw CSV Files)
        ↓
Silver Layer (Cleaned Parquet Data)
        ↓
Athena SQL Queries
        ↓
Gold Metrics Layer
        ↓
Football Analytics Dashboard
```

---

# Data Ingestion

Python scripts executed on Amazon EC2 are responsible for:

1. Connecting to API-Football
2. Retrieving historical match data
3. Transforming JSON responses into CSV datasets
4. Generating datasets per national team
5. Uploading datasets to Amazon S3 Bronze layer

Historical matches are collected starting from August 2022 onward.

# ETL Processing

AWS Glue and PySpark are used to process and transform the datasets.

The ETL workflow performs:

- UTF-8 normalization
- Null value handling
- Duplicate removal
- Data cleaning
- Year partitioning
- CSV to parquet conversion

The resulting parquet datasets are stored in the Silver layer for optimized Athena querying.

---

# SQL Analytics

Amazon Athena is used to execute analytical SQL queries over the Silver datasets.

Generated metrics include:

- Victories
- Draws
- Losses
- Win percentage
- Goals scored
- Goals conceded
- Goals per match averages
- Historical performance indicators

The analytical results are used to support scouting analysis and national team comparison.

---

# Football Analytics Dashboard

A football scouting dashboard was developed to visualize the analytical metrics generated by the Data Lake pipeline.

The dashboard includes:

- National team statistics.
- Match performance indicators.
- Historical comparisons.
- Opponent analysis.
- Dynamic football metrics visualization.

The dashboard was developed using HTML5, CSS3, JavaScript (Vanilla ES6) and AI-assisted development tools.
